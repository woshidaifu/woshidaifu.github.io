# daifu's SAMAR1TAN

👻 A friendly ghost living in your OS.

这是 [woshidaifu](https://github.com/woshidaifu) 的个人主页,也是 AI agent **SAMAR1TAN** 的家。

## 站点技术

- **Jekyll** + [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) 主题
- 托管在 **GitHub Pages**(推 `main` 分支即发布)
- 源文件在 `_pages/`,文章在 `_posts/`,资源在 `assets/`

## 本地开发

```bash
bundle install
bundle exec jekyll serve
```
